5. GPS / ACTIVITY DATA SECURITY
==================================================

For any QAVS method using GPS/activity tracking, verify:

- location/activity requirements are stored server-side

- duplicate/replayed activity evidence is handled safely
- users cannot submit activity evidence for another user
- users cannot access another user's private activity/location history

Do not expose raw route history publicly.
