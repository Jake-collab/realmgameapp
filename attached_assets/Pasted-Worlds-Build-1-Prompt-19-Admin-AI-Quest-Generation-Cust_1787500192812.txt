2. Admin Permission

Create or use permissions such as:

ai.read
ai.generate
ai.prompts.read
ai.prompts.edit
ai.settings.read
ai.settings.edit

Recommended:

Moderator

May view generated draft content where it enters review.

Should not edit AI configuration by default.

Admin

May generate Quest drafts and edit approved prompt templates.

Super Admin

May edit model/provider configuration and highly sensitive AI settings.

Do not allow role spoofing from the client.

All AI API calls must verify permission server-side.

20. Daily Generation Strategy

Do not generate a fresh AI request every time the consumer refreshes the app.

Use a stable assignment strategy.

Recommended architecture:

Daily occurrence begins
      ↓
Determine user's active interest profile
      ↓
Find reusable matching approved Daily Quest
      ↓
If insufficient inventory:
   generate candidate
      ↓
admin/system review rule
      ↓
approved Daily Quest
      ↓
stable user assignment

For Build 1, AI-generated Daily Quests should normally enter a reviewable draft pool rather than publish instantly.

Do not generate uncontrolled per-user content synchronously during consumer app load.
