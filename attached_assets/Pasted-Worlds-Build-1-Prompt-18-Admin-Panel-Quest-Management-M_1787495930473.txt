The application is named:

Worlds

Prompts 1–17 created the consumer-facing application, Quest and Hunt gameplay, progression, social systems, creator Hunt creation, moderation readiness, mapping, proof, points, privacy, and security architecture.

This prompt must implement the full internal Worlds Admin Panel foundation and operational workflows.

This is a staff application.

Ordinary users must never gain access through client manipulation.

Do not duplicate consumer-facing systems.

Do not implement Stripe, payments, creator payouts, paid Hunts, or subscriptions.

Do not connect the external AI API yet.

The next prompt will implement the customizable AI generation system for:

* Daily Quests
* Monthly Quest Drops
* Geo-Quests

including admin-editable system prompts and generation instructions.

However, this prompt must build the admin Quest editor and all database/UI surfaces the AI system will later populate.
