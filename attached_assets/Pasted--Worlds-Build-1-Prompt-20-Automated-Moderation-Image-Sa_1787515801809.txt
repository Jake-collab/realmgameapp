# 1. Core Principle

Automation may:

- Approve clearly safe low-risk content when configured
- Flag questionable content
- Quarantine content
- Route to manual review
- Calculate integrity risk
- Prioritize moderation queues

Automation must NOT automatically:

- Permanently ban a user
- Permanently suspend a user
- Delete historical evidence
- Reverse major point balances without trusted policy
- Reject ambiguous safety-sensitive cases without review
- Expose moderation internals to ordinary users

High-impact enforcement must remain reviewable.
