# Build 1 — Step 1: Project Foundation & Architecture

You are building a brand-new production-quality mobile application from scratch. There is no legacy code to preserve.

This application must be designed to scale over many years, so prioritize clean architecture, maintainability, modularity, and performance over speed.

Do **not** implement Quest gameplay, Hunt gameplay, Mapbox, AI generation, payments, or advanced features yet. Those will each be implemented in later steps.

Your goal in this step is to create the foundation that every later feature will build upon.

---

## Technology Stack

Use:

* React Native with Expo (latest stable version)
* Expo Router
* TypeScript
* Supabase (authentication, database, storage, row-level security)
* React Query (TanStack Query)
* Zustand for lightweight client state
* React Hook Form
* Zod validation
* NativeWind (Tailwind for React Native)
* React Native Reanimated
* React Native Gesture Handler

Organize the project using scalable feature-based architecture.

---

## Project Structure

Create a clean folder structure similar to:

/app

/components

/features

/shared

/services

/hooks

/lib

/types

/constants

/assets

/supabase

/docs

Use feature folders wherever appropriate.

Avoid placing everything into one large components folder.

## Environment Configuration

Create proper environment support.

Prepare placeholders for:

* Supabase URL
* Supabase anonymous key
* Mapbox access token
* AI API key (server-side only later)

Do not hardcode credentials.

Document where each value belongs.
