# Offline Capability Matrix

| Area | Cached read | Local draft | Queue | Online required |
| --- | --- | --- | --- | --- |
| Quest content | Previously loaded | Proof draft | Explicit proof intent | Start, location, submit, completion |
| Hunt | Authorized current clue only | Proof/riddle draft | Explicit proof intent | Start, unlock, completion |
| Creator Hunt | Existing draft | Yes | Draft save/media intent | Review, invites, publication |
| Notifications | Existing inbox | Read state | Yes | New data |
| Progress/social | Safe cached projection | No | No for safety actions | Fresh state and protected mutations |
| Admin/AI/moderation | Minimal cached read | No | No | All mutations |
