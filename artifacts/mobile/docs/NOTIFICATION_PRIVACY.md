# Notification Privacy

Notification records and push payloads contain only safe user-facing copy and minimal metadata. Provider responses, confidence scores, reporter identity, internal moderator notes, anti-cheat signals, private proof text, exact coordinates, hidden Hunt data, and riddle answers are never exposed.

In-app records remain available when push is disabled. Account/security messages may use a separate policy from engagement preferences. Delivery telemetry is operational data, protected from ordinary users, and subject to bounded retention.
